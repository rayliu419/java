编辑距离 Edit Distance

问题：给定两个单词 word1 和 word2，请计算将 word1 转换成 word2 所使用的最少操作数。你可以对一个单词进行以下三种操作：

  • 插入一个字符
  • 删除一个字符
  • 替换一个字符
核心心法：编辑距离是经典的双序列 DP（Two-Sequence DP）问题。核心思想是：word1[0..i] 到 word2[0..j] 的最小编辑距离，只取决于两个字符串的最后一个字符是否相等，以及前一步的三个状态。

DP 五步法

Step 1 确定 dp 数组及下标含义

定义 dp[i][j] 表示以下含义：

dp[i][j] = 将 word1[0..i-1]（长度为 i 的前缀）转换成 word2[0..j-1]（长度为 j 的前缀）所需的最少操作数。

为什么是 i-1 和 j-1 而不是 i 和 j？因为这样可以让 dp 数组的下标 0 表示空串，方便处理边界条件。

最终答案即 dp[m][n]，其中 m = word1.length()，n = word2.length()。

Step 2 确定递推公式

对于 dp[i][j]，我们考虑 word1[i-1] 和 word2[j-1] 的关系：

情况 1：word1[i-1] == word2[j-1]

最后一个字符已经相等，不需要额外操作，直接继承 dp[i-1][j-1]：

dp[i][j] = dp[i-1][j-1]

情况 2：word1[i-1] != word2[j-1]

需要做一次操作，有三种选择，取最小值：

操作 转移方程 含义
删除 dp[i-1][j] + 1 删除 word1[i-1]，word1[0..i-2] 去匹配 word2[0..j-1]
插入 dp[i][j-1] + 1 在 word1[i-1] 后插入 word2[j-1]，word1[0..i-1] 去匹配 word2[0..j-2]
替换 dp[i-1][j-1] + 1 将 word1[i-1] 替换为 word2[j-1]

综合起来：

if (word1[i-1] == word2[j-1]) {
    dp[i][j] = dp[i-1][j-1];
} else {
    dp[i][j] = min(
        dp[i-1][j] + 1,    // 删除
        dp[i][j-1] + 1,    // 插入
        dp[i-1][j-1] + 1   // 替换
    );
}
易错点：很多人会漏掉"替换"操作（只记得删除和插入）。替换是三种操作中最直观的，对应 dp[i-1][j-1] + 1——把 word1[i-1] 直接改成 word2[j-1]，然后看剩下的前缀。
为什么删除和插入是对称的？对 word1 做删除就等价于对 word2 做插入，所以 dp[i-1][j] 和 dp[i][j-1] 本质上是同一个操作的两种视角。二者都得考虑是因为我们只对 word1 操作。

Step 3 初始化 dp 数组

边界条件：当其中一个字符串为空时，编辑距离就是另一个字符串的长度（全部插入或全部删除）。

初始化项 含义 值
dp[0][j] = j 空串 → word2[0..j-1] 插入 j 个字符
dp[i][0] = i word1[0..i-1] → 空串 删除 i 个字符
dp[0][0] = 0 空串 → 空串 不需要操作 
// 初始化 (m+1) x (n+1) 矩阵
int m = word1.length(), n = word2.length();
int[][] dp = new int[m + 1][n + 1];

// 第一行：空串变到 word2
for (int j = 0; j <= n; j++) dp[0][j] = j;

// 第一列：word1 变到空串
for (int i = 0; i <= m; i++) dp[i][0] = i;

Step 4 确定遍历顺序

从递推公式可以看出，dp[i][j] 依赖三个方向：

  • 上方：dp[i-1][j]
  • 左方：dp[i][j-1]
  • 左上方：dp[i-1][j-1]

所以必须从上到下、从左到右遍历。保证计算 dp[i][j] 时，它的上面、左面、左上角都已经计算完毕。

for (int i = 1; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (word1.charAt(i-1) == word2.charAt(j-1)) {
            dp[i][j] = dp[i-1][j-1];
        } else {
            dp[i][j] = Math.min(dp[i-1][j-1],
                         Math.min(dp[i-1][j], dp[i][j-1])) + 1;
        }
    }
}
return dp[m][n];
能不能 j 在外层、i 在内层？可以。只要保证 dp[i][j] 依赖的三个方向已计算即可。先遍历 word1 还是 word2 不影响结果（对称性）。

dp 回溯详解

从 dp[5][3] = 3 沿最优路径回推（从右下到左上），理解每一步的决策：

位置比较转移来源操作
dp[5][3]=3 e ≠ s 上 dp[4][3]=2（最小）+1 删除 word1 的 e
dp[4][3]=2 s = s dp[3][2]（继承左上角） 跳过（无需操作）
dp[3][2]=2 r ≠ o 上 dp[2][2]=1（最小）+1 删除 word1 的 r
dp[2][2]=1 o = o dp[1][1]（继承左上角） 跳过（无需操作）
dp[1][1]=1 h ≠ r 左上 dp[0][0]=0（最小）+1 替换 h → r
dp[0][0]=0 初始空串 → 空串，基线条件

最优操作序列（将回溯结果正向执行）：

  1. 替换 h → r：horse → rorse（对应 dp[1][1] 的替换决策）
  2. 跳过 o：无需操作，字符串不变
  3. 删除 位置 2 的 r：rorse → rose（对应 dp[3][2] 的删除决策）
  4. 跳过 s：无需操作
  5. 删除 e：rose → ros（对应 dp[5][3] 的删除决策）

共 3 步（替换 + 2 次删除），最终得到 ros。✔

关键领悟：dp 回溯是从问题的终点逆向推导到起点。在实际编程中，我们只需要 dp[m][n] 这个数值，不需要真的回溯出操作序列。但理解回溯过程能帮你深入理解编辑距离的递推逻辑。

完整代码（Java）

public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];

    // 初始化
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 0; i <= m; i++) dp[i][0] = i;

    // 递推
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = Math.min(Math.min(
                    dp[i - 1][j],     // 删除
                    dp[i][j - 1]),    // 插入
                    dp[i - 1][j - 1]  // 替换
                ) + 1;
            }
        }
    }
    return dp[m][n];
}

空间优化（滚动数组）

观察递推公式，dp[i][j] 只依赖 dp[i-1][j]（上一行）、dp[i][j-1]（当前行左边）和 dp[i-1][j-1]（左上角），所以可以用一维数组 + 一个变量记录左上角值。

public int minDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[] dp = new int[n + 1];

    // 初始化第一行
    for (int j = 0; j <= n; j++) dp[j] = j;

    for (int i = 1; i <= m; i++) {
        int prev = dp[0];     // 相当于 dp[i-1][j-1]
        dp[0] = i;            // 相当于 dp[i][0] = i
        for (int j = 1; j <= n; j++) {
            int temp = dp[j]; // 暂存旧的 dp[j]（即 dp[i-1][j]）
            if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                dp[j] = prev; // 继承左上角
            } else {
                dp[j] = Math.min(Math.min(
                    temp,          // 删除：dp[i-1][j]
                    dp[j - 1]),    // 插入：dp[i][j-1]
                    prev           // 替换：dp[i-1][j-1]
                ) + 1;
            }
            prev = temp;       // 下一轮的左上角就是当前的 dp[i-1][j]
        }
    }
    return dp[n];
}
滚动数组的关键：左下角 prev 需要在被覆盖之前保存。每次更新 dp[j] 前，先把旧值存到 temp，然后赋值给 prev供下一列使用。

扩展与应用

  • 拼写纠错：编辑距离最小的候选词作为建议
  • DNA 序列对齐：衡量基因序列的相似度
  • 抄袭检测：两段文本的编辑距离越小，相似度越高
  • 版本差异 diff：基于编辑距离的思想计算最小变更

五步法总结：

  1. dp 定义：dp[i][j] = word1 前 i 个字符 → word2 前 j 个字符的最小编辑距离
  2. 递推公式：字符相等则 dp[i-1][j-1]；不相等则 min(删除, 插入, 替换) + 1
  3. 初始化：第一行 dp[0][j] = j，第一列 dp[i][0] = i
  4. 遍历顺序：从上到下，从左到右（两层 for 循环）
  5. 举例验证：horse → ros = 3 步
