1. Dedup / Remove（去重与删除）

核心性质：去重 / 删除本质是同一个动作——「保留满足条件的元素」。按载体选骨架：数组用快慢指针原地覆盖，链表用dummy + prev 跳过，相邻重复用栈（栈顶即「前一个」），连续成组用整组跳过。共同点：一次遍历，只留该留的。

通用模版

// 骨架一：数组 / 字符数组原地过滤（快慢指针）
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (需要保留 nums[fast]) {
        nums[slow++] = nums[fast];
    }
}
return slow;                    // 新长度，尾部残留忽略

// 骨架二：链表按条件删除（dummy + prev）
ListNode dummy = new ListNode(0, head);   // 头可能被删，必须 dummy
ListNode prev = dummy, cur = head;
while (cur != null) {
    if (需要删除 cur) prev.next = cur.next;   // 跳过，prev 不动
    else prev = cur;                          // 保留，prev 跟进
    cur = cur.next;
}
return dummy.next;

// 骨架三：相邻重复消除（栈：栈顶 = 前一个）
Deque<Character> stack = new ArrayDeque<>();
for (char c : s.toCharArray()) {
    if (!stack.isEmpty() && stack.peek() == c) stack.pop();  // 相同 → 抵消
    else stack.push(c);
}

// 骨架四：连续成组整体处理（先找整组 [i, j)，再按组决定）
int i = 0;
while (i < n) {
    int j = i;
    while (j < n && s.charAt(j) == s.charAt(i)) j++;   // 找到整组
    if (整组要保留) sb.append(...);                     // 或按组计数
    i = j;                                              // 跳过整组
}

解题模版

先定载体: 数组 → 快慢指针；链表 → dummy+prev；相邻重复 → 栈
保留条件: 想清楚「什么该留」，核心就是 if (保留) 一个动作
链表头可变: 一律 dummy，返回 dummy.next
String 不可变: 转 char[] 原地写，或 StringBuilder 拼接
栈的抵消: 栈顶 = 前一个元素，相同即 pop
非连续去重: Set 标记已见，保留首次出现（保序）

2. Binary Search（二分查找）

核心性质：每一轮都保证答案仍在 [low, high] 中，用 mid 排除不可能的一半，直到区间为空或只剩一个元素。

通用模版

int binarySearch(int[] nums, int target) {
    int low = 0, high = nums.length - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;   // 防溢出
        if (nums[mid] == target) return mid;
        else if (nums[mid] > target) high = mid - 1;
        else low = mid + 1;
    }
    return -1;   // 未命中时 low 是插入位置
}

// lower_bound：第一个 >= target 的位置
int low = 0, high = nums.length - 1;
while (low < high) {
    int mid = low + (high - low) / 2;   // high = mid，必须下取整
    if (nums[mid] >= target) high = mid;
    else low = mid + 1;
}
return nums[low] >= target ? low : nums.length;

解题模版

搜索区间: [low, high]
循环条件: low <= high（排除式） / low < high（保留式）
mid 取整: 排除式下取整；保留 high=mid 时下取整
收缩规则: 能排除 mid 就 mid ± 1；可能保留 mid 才写 high = mid
答案位置: 命中时循环内返回；未命中时 low 或 ans

3. Sliding Window（滑动窗口）

核心性质：适用于连续子串 / 子数组问题；左右指针维护窗口，变化点只有窗口状态、扩张 / 收缩条件、答案更新时机。

通用模版

// 固定窗口，大小 k
for (int i = 0; i < k; i++) add(i);
if (check()) return ...;
for (int i = k; i < n; i++) {
    add(i);
    remove(i - k);
    if (check()) return ...;
}

// 最大窗口：窗口不合法时收缩，收缩后更新答案
int left = 0, answer = 0;
for (int right = 0; right < n; right++) {
    add(right);
    while (windowIsInvalid()) { remove(left); left++; }
    answer = Math.max(answer, right - left + 1);
}

// 最小窗口：窗口合法时尽量收缩，收缩循环内更新答案
int left = 0, answer = Integer.MAX_VALUE;
for (int right = 0; right < n; right++) {
    add(right);
    while (windowIsValid()) {
        answer = Math.min(answer, right - left + 1);
        remove(left); left++;
    }
}
return answer == Integer.MAX_VALUE ? 0 : answer;

解题模版

窗口范围: [left, right]
窗口状态:
窗口扩张:
窗口收缩:
触发收缩的条件:
答案更新时机:

4. Evaluation（表达式求值）

核心性质：所有变体共享一个循环：数字拼接 → 遇到触发条件 → 结算并更新状态。关键只有「什么时候触发结算」，以及结算时哪些变量需要更新。

通用模版

// 只适配无括号表达式：仅 + -，或 + - * /。带括号版本见 evaluation.html §3.3
int res = 0, num = 0;
char sign = '+';              // 虚拟开头符
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
    if (Character.isDigit(c)) num = num * 10 + (c - '0');

    if (c == '+' || c == '-' || c == '*' || c == '/' || i == s.length() - 1) {
        // 无括号版：用上一个 sign 结算 num（括号版 switch 分派对象换成当前 c）
        switch (sign) { ... }
        sign = c;
        num = 0;
    }
}

解题模版

触发条件: 新运算符 / 虚拟结尾符 i == len-1
结算对象: 上一个 sign 管辖的 num
额外状态: 只含 +- 无；含 * / 加 lastNum
循环外收尾: 含 * / 需要 res += lastNum
不适配: 带括号（224 / 772）——switch 分派对象换成 c，见 evaluation.html §3.3

举例：每道题改了模版的哪里

题目对模版的改动
只含 + -（基础形态）— 触发集合只留 + - 与末尾；无额外状态，循环内已结算完，循环外无需收尾。
227. Basic Calculator II— 有 * /；新增 lastNum 作为待定项，前一个 sign 是 + - 才把 lastNum 冲入 res，循环结束再 res += lastNum。

5. DFS / Backtracking（回溯）

核心性质：回溯 = DFS + 状态重置。所有题共用「路径 - 选择 - 结束条件」骨架，差别只在状态传递方式（startIndex / used[]）和剪枝条件。

通用模版

void backtrack(path, choices) {
    if (满足结束条件) { result.add(copy(path)); return; }
    for (choice in choices) {
        if (不合法) continue;      // 剪枝
        做选择;                    // path.add / used[i] = true
        backtrack(newPath, newChoices);
        撤销选择;                  // path.remove / used[i] = false
    }
}

解题模版

路径 path: 当前已选的元素
选择列表: for 循环的起点或 used[] 标记
结束条件: path.size() == n / start == len / target == 0
剪枝: 不合法直接 continue
撤销: 共享可变对象必须 remove / used 还原

6. BFS（广度优先搜索）

核心性质：BFS 按层扩展，无权图首达即最短。一个 queue + size 模板覆盖层次遍历、多源 BFS、矩阵 BFS、拓扑排序。

通用模版

// 层序遍历 / 最短路径
Queue<Node> queue = new ArrayDeque<>();
queue.offer(start); visited.add(start);
int step = 0;
while (!queue.isEmpty()) {
    int size = queue.size();
    for (int i = 0; i < size; i++) {
        Node cur = queue.poll();
        // 处理当前节点
        for (Node next : neighbors(cur)) {
            if (!visited.contains(next) && 条件) {
                visited.add(next);
                queue.offer(next);
            }
        }
    }
    step++;   // 一层结束
}

// 矩阵 BFS 四方向
int[] dirs = {0, 1, 0, -1, 1, 0, -1, 0};
int nx = cur[0] + dirs[d], ny = cur[1] + dirs[d + 1];

解题模版

起点: 单源一个入队 / 多源全部入队
队列状态: 当前层所有节点
扩展规则: 邻居满足条件且未访问才入队
visited 时机: 入队前标记，不能出队时再标
答案位置: 出队时处理，或每层结束时 step++

7. Prefix Sum / Difference（前缀和与差分）

核心性质：子数组和 = 两个前缀和之差。用 prefix[i] 统一 [0, i) 的累加，配合 HashMap 统计差值；区间批量更新用差分数组。

通用模版

int[] prefix = new int[n + 1];
for (int i = 1; i <= n; i++) prefix[i] = prefix[i - 1] + nums[i - 1];
// 任意子数组 [i, j) 的和：prefix[j] - prefix[i]

// 前缀和 + HashMap：和为 k 的子数组个数
Map<Integer, Integer> map = new HashMap<>();
map.put(0, 1);
for (int x : nums) {
    cur += x;
    ans += map.getOrDefault(cur - k, 0);
    map.merge(cur, 1, Integer::sum);
}

// 差分：区间 [l, r] 加 val
diff[l] += val;
diff[r + 1] -= val;

解题模版

前缀定义: prefix[i] 表示前 i 个元素的和
查询: 区间和 = prefix[r+1] - prefix[l]
HashMap 初始化: put(0, 1)
更新时机: 先查 cur - k，再放入 cur
差分: 更新 O(1)，最后前缀和还原

8. Monotonic Stack（单调栈）

核心性质：栈内保持单调；遇到破坏单调性的元素时，pop 的栈顶元素就找到了答案（右边界），新元素是它之后更近的候选。

通用模版

// 右边第一个更大的元素：栈底到栈顶单调递减
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
        result[stack.pop()] = nums[i];   // pop 时结算
    }
    stack.push(i);
}

解题模版

栈中存什么: 下标，方便计算距离
单调方向: 找下一个更大 → 递减栈；下一个更小 → 递增栈
触发结算: 当前元素破坏栈单调性
结算对象: 被 pop 的栈顶元素
答案位置: pop 时写入 result

9. TopK / K-Way Merge

核心性质：TopK 两条路：QuickSelect 平均 O(n) 适合内存数据；容量 K 的堆适合数据流。K 个有序序列合并统一用「K 个头入堆，poll 后 push 该序列下一个」。

通用模版

// QuickSelect：在 [low, high] 找第 k 小（k 是相对排名）
int p = partition(nums, low, high);
int rank = p - low + 1;
if (rank == k) return nums[p];
if (rank > k)  return quickSelect(nums, low, p - 1, k);
return quickSelect(nums, p + 1, high, k - rank);

// K-Way Merge
PriorityQueue<Node> heap = new PriorityQueue<>(Comparator.comparingInt(n -> n.val));
for (Node head : lists) heap.offer(head);
while (!heap.isEmpty()) {
    Node cur = heap.poll();
    if (cur.next != null) heap.offer(cur.next);   // push 该序列下一个
}

解题模版

堆里存什么: 每个序列的当前头
比较器: 需要什么顺序就怎么比
poll 后做什么: 收集答案；push poll 元素所在序列的 next
TopK 用容量 K 堆: 超过 K 就淘汰堆顶
QuickSelect 注意: k 是相对排名，不是全局下标

10. Two Pointer（双指针）

核心性质：对撞指针从两端向中间收缩，常用于有序数组找配对；同向快慢指针常用于去重、找中点、环检测。每轮只移动「不可能更优」的那一边。

通用模版

// 对撞指针
int i = 0, j = n - 1;
while (i < j) {
    if (不满足条件) i++;
    else if (另一侧不满足) j--;
    else { 处理答案; i++; j--; }
}

// 同向快慢指针
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (需要保留 nums[fast]) {
        nums[slow++] = nums[fast];
    }
}

解题模版

指针起点: 两端 i=0, j=n-1 / 同向 slow=0, fast=0
移动规则: 谁不可能更优就移动谁
去重: 先排序，相等时跳过相邻重复
答案时机: 满足条件时记录，再同时收缩或推进

11. Intervals（区间）

15. Binary Search Tree（二叉搜索树）

核心性质：BST 左小右大，遍历即二分。骨架收敛为两类：「找」——比较 target 与 root.val 只走一侧；「改」——修改后返回新子树根，父节点必须接收返回值。另有两条特权：中序遍历有序、有序数组构造即平衡。

通用模版

// 骨架一：查找（树的二分，类似二分查找只搜一侧）
TreeNode search(TreeNode root, int target) {
    if (root == null) return null;
    if (root.val == target) return root;
    if (root.val < target) return search(root.right, target);
    return search(root.left, target);
}

// 骨架二：增 / 删（改 → 返回新根并接收）
TreeNode insert(TreeNode root, int val) {
    if (root == null) return new TreeNode(val);   // 空位即插入点
    if (root.val < val) root.right = insert(root.right, val);
    else if (root.val > val) root.left = insert(root.left, val);
    return root;
}

TreeNode delete(TreeNode root, int key) {
    if (root == null) return null;
    if (root.val == key) {
        if (root.left == null) return root.right;  // 0 / 1 个孩子
        if (root.right == null) return root.left;
        TreeNode min = getMin(root.right);         // 两个孩子：右子树最小顶上
        root.val = min.val;
        root.right = delete(root.right, min.val);
    } else if (root.val > key) {
        root.left = delete(root.left, key);
    } else {
        root.right = delete(root.right, key);
    }
    return root;
}

// 骨架三：中序遍历（BST 有序性入口）
void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    // 处理当前节点：第 k 小 / 相邻最小差 / 验证严格递增
    inorder(root.right);
}

// 骨架四：有序数组建树（取中点 → 天然平衡）
TreeNode build(int[] nums, int lo, int hi) {
    if (lo > hi) return null;
    int mid = lo + (hi - lo) / 2;
    TreeNode root = new TreeNode(nums[mid]);
    root.left = build(nums, lo, mid - 1);
    root.right = build(nums, mid + 1, hi);
    return root;
}

解题模版

遍历框架: 比较 target 与 root.val 只走一侧，类似二分
改的返回: 修改类操作返回 TreeNode，父节点必须 root.left/right = 接收
删除三态: 叶子返回 null；单孩子返回该孩子；双孩子用右子树最小（或左子树最大）顶上
验证合法性: 只查左右孩子不够（漏跨层违例）；辅助函数传 (min, max) 边界约束整棵子树
中序遍历: 有序 → 第 k 小、相邻最小差、两数之和、验证递增
构造: 有序数组取中点递归两侧；前序 + 值域边界也可构造
LCA: 两节点同侧只搜该侧，走到分叉点即答案

16. Union-Find（并查集）

核心性质：管理「元素是否属于同一集合」：只有 find（找根）和 union（合并）两个操作。路径压缩 + 按秩合并后近似 O(1)。图的连通性问题（岛屿、朋友圈、冗余连接、账户合并）统一用它，替代 BFS/DFS 染色。

通用模版

class UnionFind {
    int[] parent, rank;
    int count;                          // 连通分量个数
    UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        count = n;
    }
    int find(int x) {                   // 找根 + 路径压缩
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    void union(int x, int y) {          // 合并两棵树
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        if (rank[rx] < rank[ry]) parent[rx] = ry;   // 矮树挂到高树下
        else if (rank[rx] > rank[ry]) parent[ry] = rx;
        else { parent[ry] = rx; rank[rx]++; }
        count--;
    }
    boolean connected(int x, int y) { return find(x) == find(y); }
}

解题模版

find: 递归找根，返回时顺手路径压缩
union: 先 find 两个根，同根无事发生；按秩合并，count--
连通分量: 每成功 union 一次 count--，count 即剩余分量数
元素映射: 非 0..n-1 的元素（如字符串）先 map 到下标
建图时机: 所有边先 union 一遍，再按根聚合分组

17. Trie（前缀树）

核心性质：多叉树存字符串集合，每个节点一个字符，公共前缀共享。插入 / 查询复杂度 O(词长)，与集合大小无关。字典、自动补全、前缀匹配、网格单词搜索先想到它。

通用模版

class Trie {
    private static class Node {
        Node[] next = new Node[26];
        boolean isEnd;
    }
    private Node root = new Node();

    void insert(String word) {
        Node p = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (p.next[i] == null) p.next[i] = new Node();
            p = p.next[i];
        }
        p.isEnd = true;
    }

    boolean search(String word) {        // 完整单词
        Node p = find(word);
        return p != null && p.isEnd;
    }

    boolean startsWith(String prefix) {  // 前缀
        return find(prefix) != null;
    }

    private Node find(String s) {
        Node p = root;
        for (char c : s.toCharArray()) {
            p = p.next[c - 'a'];
            if (p == null) return null;
        }
        return p;
    }
}

解题模版

节点: 26 叉数组（或 HashMap 支持任意字符）+ isEnd 标记
查询三件套: insert / search / startsWith，后两个共用 find
通配符: 递归 DFS，遇到 '.' 遍历所有孩子
树上搜索: 网格单词搜索用 Trie 剪枝 + 回溯，命中 isEnd 即收集
空间: 每个单词的字符都建节点，字典大时考虑压缩

18. Topological Sort（拓扑排序）

核心性质：有向无环图（DAG）的线性排序：所有边都从前指向后。判环 + 求合法顺序统一用 Kahn 算法（入度表 + BFS）：入度为 0 才能出队，出队数 < 节点数说明有环。

通用模版

// Kahn：入度表 + 队列
int[] indegree = new int[n];
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
for (int[] e : edges) {
    graph.get(e[0]).add(e[1]);
    indegree[e[1]]++;
}

Queue<Integer> q = new ArrayDeque<>();
for (int i = 0; i < n; i++) if (indegree[i] == 0) q.offer(i);

int[] order = new int[n];
int idx = 0;
while (!q.isEmpty()) {
    int cur = q.poll();
    order[idx++] = cur;
    for (int next : graph.get(cur))
        if (--indegree[next] == 0) q.offer(next);
}
// idx < n 说明有环，无法完成

解题模版

判环: 出队节点数 != 总节点数 → 有环
字典序: 队列换成 PriorityQueue

19. Two Heaps（双堆）

核心性质：把数据流切成两半：大顶堆放较小一半、小顶堆放较大一半，中位数就是两堆堆顶。动态集合反复求中位数 / 极值差，两个堆互为镜像。

通用模版

// 295. Find Median from Data Stream
PriorityQueue<Integer> lo = new PriorityQueue<>(Collections.reverseOrder()); // 较小一半（大顶堆）
PriorityQueue<Integer> hi = new PriorityQueue<>();                           // 较大一半（小顶堆）

void addNum(int num) {
    lo.offer(num);
    hi.offer(lo.poll());          // 平衡：把 lo 的最大值挪到 hi
    if (lo.size() < hi.size())    // 保持 lo.size() == hi.size() 或 lo 多 1
        lo.offer(hi.poll());
}

double findMedian() {
    return lo.size() > hi.size()
        ? lo.peek()
        : (lo.peek() + hi.peek()) / 2.0;
}

解题模版

分工: 较小一半 → 大顶堆；较大一半 → 小顶堆
平衡律: 插入后必须 lo.size() >= hi.size() 且差值 <= 1
中位数: 奇数个取 lo.peek()，偶数个两堆顶平均
滑窗中位数: 双堆 + 延迟删除（lazy removal）
贪心组合: 先按某键排序，另一维用堆挑最优（如 IPO）

20. Monotonic Deque（单调队列）

核心性质：与单调栈对称：栈管「左右最值」，队列管「滑动窗口最值」。窗口滑动时队首就是窗口最值；新元素从队尾淘汰比它更小的旧元素——它们不可能再成为答案。

通用模版

// 239. Sliding Window Maximum
int n = nums.length, k = ...;
int[] ans = new int[n - k + 1];
Deque<Integer> dq = new ArrayDeque<>();   // 存下标，值从队首到队尾单调递减
for (int i = 0; i < n; i++) {
    while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i])
        dq.pollLast();                    // 淘汰队尾更小/相等的
    dq.offerLast(i);
    while (dq.peekFirst() <= i - k)
        dq.pollFirst();                   // 队首出窗口
    if (i >= k - 1) ans[i - k + 1] = nums[dq.peekFirst()];
}

解题模版

单调方向: 求最大值 → 递减队列；求最小值 → 递增队列
存下标: 存下标才能判断元素是否已出窗口
淘汰规则: 新元素 >= 队尾值时，队尾永远当不了答案，pop
过期规则: 队首下标 <= i - k 时出队
答案时机: 窗口满（i >= k-1）后每次取队首

21. LRU Cache / 设计类

核心性质：设计题考「数据结构选型」：O(1) 查找 → HashMap；O(1) 维护顺序 → 双向链表。LRU = HashMap + 双向链表：get 命中移到头部，put 新增放头部、超容量删尾部。

通用模版

// 146. LRU Cache
class LRUCache {
    private static class Node {
        int key, val;
        Node prev, next;
        Node(int k, int v) { key = k; val = v; }
    }
    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head = new Node(0, 0), tail = new Node(0, 0); // 哑节点

    LRUCache(int capacity) {
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    int get(int key) {
        Node node = map.get(key);
        if (node == null) return -1;
        moveToHead(node);
        return node.val;
    }

    void put(int key, int value) {
        if (map.containsKey(key)) {
            Node node = map.get(key);
            node.val = value;
            moveToHead(node);
        } else {
            Node node = new Node(key, value);
            map.put(key, node);
            addToHead(node);
            if (map.size() > capacity) {        // 超容量删最久未用
                Node last = tail.prev;
                removeNode(last);
                map.remove(last.key);
            }
        }
    }
    // addToHead / removeNode / moveToHead 三个链表原语
}

解题模版

选型: O(1) 查 → HashMap；O(1) 顺序变更 → 双向链表
哑节点: head / tail 哑节点避免判空
三个原语: addToHead / removeNode / moveToHead，业务逻辑全用它们拼
变体: LFU 加频次桶；Min Stack 用辅助栈存当前最小值
面试要点: 先讲清选型理由，再写代码

22. Cyclic Sort（原地哈希）

核心性质：元素值域与下标域一致（1..n 或 0..n-1）时，把每个值送回「它该在的位置」，一趟交换完成找缺失 / 找重复，O(n) 时间 O(1) 空间。

通用模版

// 值在 [1, n]：目标下标 = 值 - 1
int i = 0;
while (i < n) {
    int target = nums[i] - 1;
    if (nums[i] == i + 1) i++;              // 已在正确位置
    else if (nums[target] == nums[i]) i++;  // 目标位已有同值 → 重复
    else swap(nums, i, target);             // 否则送回正确位置
}
// 归位后扫一遍：nums[i] != i + 1 的位置 i 就是缺失 / 重复

解题模版

适用条件: 值域与下标域对齐（1..n → 下标 0..n-1）
交换: 把 nums[i] 送到下标 nums[i]-1，直到当前位置正确
重复检测: 目标位已有同值 → 重复数
缺失检测: 归位后扫一遍，nums[i] != i+1 即缺失
值域含 0 / 负数: 先过滤或映射（如 41 题只处理 1..n）

41. First Missing Positive— 只处理 1..n 范围内的值，归位后第一个错位位置 + 1 即答案。

23. Tree 递归套路（遍历 vs 分解）

核心性质：二叉树递归只有两种视角：遍历——void 递归 + 外部变量收集答案；分解——递归返回子树结果给父节点组装（多数是后序）。看到树的题先问：答案是「一路收集」还是「子树拼装」？

通用模版

// 视角一：遍历（void 递归 + 外部变量）
int ans = 0;
void traverse(TreeNode root) {
    if (root == null) return;
    // 前序：进节点时处理，更新 ans
    traverse(root.left);
    // 中序：BST 有序处理
    traverse(root.right);
    // 后序：子树都处理完
}

// 视角二：分解（返回子树结果，父节点组装）
int solve(TreeNode root) {
    if (root == null) return base;          // base case
    int left = solve(root.left);            // 先算子树
    int right = solve(root.right);
    // 后序：用 left / right 组装返回给父节点的值
    return combine(root, left, right);
}

// 视角三：返回值 + 外部答案（543 直径）
// 递归返回高度，同时用 left + right 更新全局最大直径
int height(TreeNode root) {
    if (root == null) return 0;
    int l = height(root.left), r = height(root.right);
    ans = Math.max(ans, l + r);             // 经过当前节点的最长路径
    return 1 + Math.max(l, r);              // 返回给父节点的高度
}

解题模版

先问视角: 答案靠一路收集（遍历）还是子树拼装（分解）？
base case: 空节点返回什么（0 / null / 特殊值）
返回语义: 分解视角必须定义清楚「返回给父节点什么」
处理时机: 前序 = 进节点时处理；后序 = 子结果就绪后处理（多数树题用后序）
多返回值: 一个返回值不够时（高度 + 答案），用外部变量或数组
