416 分割等和子集：为什么内层循环必须倒序？

问题：给定数组，能否选出一些数，使它们的和 = 总和的一半？
性质：每个数只能用一次 → 0-1 背包 → 内层循环必须倒序

一、代码结构

public boolean canPartition(int[] nums) {
    int sum = 0;
    for (int num : nums) sum += num;
    if (sum % 2 != 0) return false;

    int target = sum / 2;
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;                           // 空集，和为 0

    for (int num : nums) {                    // 外循环：逐个看每个数字
        for (int s = target; s >= num; s--) { // 内循环：倒序
            dp[s] = dp[s] || dp[s - num];     // 不取 || 取
        }
    }
    return dp[target];
}

关键就一行：for (int s = target; s >= num; s--)。
改成 s = num; s <= target; s++ 就是完全不同的语义——从 0-1 背包变完全背包。

反直觉的规律：「每个数用一次」时内循环是倒序；「每个数可以用多次」时内循环反而是正序。 这跟 coin change、word break 是同一个道理——那些题里每个单词/硬币可以重复用，所以 dp 是正着算的。

二、核心逻辑：dp[s] = dp[s] || dp[s - num]

这行代码的两个分支：

  • dp[s]（旧值）→ 之前就能凑出 s，跳过当前 num
  • dp[s - num] → 之前能凑出 s-num，带上当前 num 就是 s

所以读 dp[s - num] 时，需要确保它是「还没考虑当前 num 的状态」，否则同一个 num 会被用多次。

三、为什么倒序能保证只用一次？

用 nums = [2]，target = 4 来演示，数组里只有一个 2：

✅ 倒序（正确）

dp = [T, F, F, F, F] num=2, s = 4→2 倒序: s=4: dp[4] = F || dp[2](F) = F s=3: dp[3] = F || dp[1](F) = F s=2: dp[2] = F || dp[0](T) = T 结果: dp[4] = F ✅

s=4 时读到的 dp[2] 还是 F（上一轮的值，没用过 2），所以 dp[4] = F。

❌ 正序（错误）

dp = [T, F, F, F, F] num=2, s = 2→4 正序: s=2: dp[2] = F || dp[0](T) = T ← 用了 2 s=3: dp[3] = F || dp[1](F) = F s=4: dp[4] = F || dp[2](T) = T ↑ 刚被更新为 T，又用了一次！ 结果: dp[4] = T ❌

s=4 时读到的 dp[2] 已经是 T（这轮刚更新的，已经用了 2），等同于把 2 用了两次，2+2=4。但数组里只有一个 2！

本质：倒序保证 dp[s - num] 始终是「上一轮」的值——当前数字还没参与过。
正序时 dp[s - num] 可能是「本轮刚更新」的值——当前数字已经被用过了。

四、把抽象变直觉

倒序 正序
dp[s - num] 读的是旧值（没碰过当前 num） 读的可能是新值（已碰过当前 num）
效果 每个 num 最多用一次 同一个 num 可以累积
适用场景 每个数只能用一次 每个数可以用无限次
一句话 只能拿一次，不能贪心回头 可以反复拿，越滚越大
自检：如果 416 误写成正序，对于 [1,2,3] 总和 6 → target=3，正序会把 1 重复用多次：dp[1]=T → dp[2]=T（1+1）→ dp[3]=T（1+1+1），直接返回 true，但实际上 [1,2,3] 里只有 1 个 1，不可能用三次。

五、延伸：什么题是正序？

反过来，j++ 正序的场景：每个元素可以用无限次。

题目 复用特征 内层方向
416 分割等和子集 每个数只能用一次 倒序
322 零钱兑换 每个硬币无限取 正序
139 单词拆分 每个单词无限用 正序
记忆窍门：「一次倒，多次正」——听起来反直觉，但想通了就很简单：
倒序 = 读旧值 = 当前元素还没参与 = 最多加一次
正序 = 读新值 = 当前元素已参与过 = 可以反复叠加
