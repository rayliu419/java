概览

数组或者字符串的基本操作。

  • String 主要是各种边界情况的处理或者位置的处理。
  • 数组包含给定范围内的数字，查找丢失或重复的数字。这里的通常要求是只能是 O(1) 空间。将数字放到它应该放到的位置，然后继续。

String 原地删除多余空格

核心实现：外层循环用 fast 过滤空格，内层 while 拷贝实际单词。slow != 0 时先加一个空格分隔。

for (int fast = 0; fast < s.length(); fast++) {
    if (chars[fast] != ' ') {
        if (slow != 0) chars[slow++] = ' ';
        while (fast < s.length() && chars[fast] != ' ')
            chars[slow++] = chars[fast++];
    }
}

String 去重相邻的字符

核心思路：外层 while 逐字符扫描，内层 while 跳过所有与当前字符连续相同的字符。仅当字符「完全孤立」（无任何相邻重复）时才 append，即整段删除所有连续重复段。如 "aaaabbbbc" → "c"（a、b 整段丢弃，仅保留孤立的 c）。对应 Exam.java 的 removeDuplicates。

// 外层循环：遍历输入字符串的每一个字符
while (i < n) {
    int next = i + 1;
    // 内层循环：跳过所有与当前字符连续相同的字符
    while (next < n && str.charAt(i) == str.charAt(next)) {
        next++;
    }
    if (next == i + 1) {
        sb.append(str.charAt(i));
    }
    i = next;
}
return sb.toString();

变体：保留一个（合并相邻重复）

上面的写法是不保留任何一个（整段丢弃）。若改为保留一个，只需把条件从 next == i + 1 改成 next > i（即该段至少有一个字符就保留第一个）。此时 "aaaabbbbc" → "abc"。

while (i < n) {
    int next = i + 1;
    while (next < n && str.charAt(i) == str.charAt(next)) {
        next++;
    }
    if (next > i) {            // 只要该段有字符就保留第一个
        sb.append(str.charAt(i));
    }
    i = next;
}
return sb.toString();

Reverse Word

  1. removeSpace(s) — 去除多余空格
  2. reverse(chars, 0, len-1) — 整体反转
  3. 逐单词 reverse(chars, slow, fast-1) — 恢复单词顺序

字符串相乘

竖式乘法：m 位 × n 位结果最多 m+n 位，用数组存储，双层循环从后往前累加。

旋转数组

rotate([1,2,3,4,5,6,7], k=3) → [5,6,7,1,2,3,4]

  • k > n 时：k = k % n
  • 三次翻转，O(n) 时间，O(1) 空间
① 整体翻转: [1,2,3,4,5,6,7] → [7,6,5,4,3,2,1]
② 翻转前 k: [7,6,5,4,3,2,1] → [5,6,7,4,3,2,1]
③ 翻转后 n-k: [5,6,7,4,3,2,1] → [5,6,7,1,2,3,4] ✓

查找丢失或重复的数字

题型特点：数组包含 [1, n] 范围内的数字，查找丢失或重复，要求 O(1) 空间。

核心思路：将数字放到它应该放到的位置（nums[i] 应该放到 nums[nums[i]-1]），然后遍历检查。

  • Missing Number（268）：[0, n] 中缺失的数 → 求和 / 异或
  • First Missing Positive（41）：未排序数组找缺失的最小正整数 → 原地置换（只处理 [1, n] 范围的数）
  • Find All Numbers Disappeared（448）：[1, n] 中缺失的数 → 原地标记（出现过的下标对应值取负）
  • Find the Duplicate Number（287）：[1, n] 中重复的数 → 快慢指针判环入口
  • Find All Duplicates（442）：[1, n] 中出现两次的数 → 原地标记（值→下标取反，已负则说明重复）
