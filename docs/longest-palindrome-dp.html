最长回文子串 · DP 计算顺序可视化

核心心法：定义 dp[i][j] = s[i..j] 是否为回文（i ≤ j）。 dp[i][j] 依赖 dp[i+1][j-1]（去掉首尾后的内部子串），所以必须按子串长度从小到大计算——同一长度的子串之间互不依赖。

计算顺序详解

动画展示字符串 "babad" 的 DP 计算过程。按对角线方向、从短到长逐层填充：

  1. len=1：主对角线，所有单个字符 → 全为回文（base case）
  2. len=2：第二条对角线，相邻字符 → 直接比较 s[i]==s[i+1]（base case）
  3. len≥3：后续对角线 → 依赖 dp[i+1][j-1]（内层结果）
关键：为什么不能按行扫描？计算 dp[0][3]（len=4）需要 dp[1][2]（len=2）；如果按行优先，dp[1][2] 还没算。 必须外层按长度 len 递增，内层按起点 i 遍历。
