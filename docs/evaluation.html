表达式求值：什么时候触发结算

核心洞见：表达式求值的所有变体共享同一个循环模版——数字拼接 → 遇到触发条件 → 结算并更新状态。区别只在于触发条件和结算时哪些变量需要更新。

1. 理解什么时候触发

题目触发结算的条件
只有 + -+ - | i == len-1
加入 * /+ - * / | i == len-1
加入 ()+ - ( ) | i == len-1

i == len-1 出现在每一个里——最后一个数字后面没有运算符来推动结算，必须显式兜底。

注意：结算的触发条件 必须 是独立的 if（不能是 else if），否则最后一个字符是数字时会被数字分支吃掉，漏掉结算。
重要：触发结算时用的是 上一个 op（存在 sign 里），不是当前字符 c。c 只是扳机，扣动后 c 自己变成新的 sign 留给下一轮。

2. 理解触发时什么状态需要更新

符号结算操作重置的变量
+ - res += sign * num num = 0，sign 更新为当前符号
* / lastNum = lastNum */ num（不动 res） num = 0，sign 更新为当前符号
( stack.push(res); stack.push(sign)，开启新上下文 res = 0，sign = 1，num = 0
) res += sign * num，然后 pop 合并外层 num = 0
口诀：运算符越多，延迟越多——± 立即结算，±*/ 需缓冲 lastNum，±() 需栈暂存外层上下文。

3. 通用算法模版

3.1 加减法（仅 + 和 -）

int calculateAddMinus(String s) {
    if (s == null || s.isEmpty()) return 0;

    int res = 0;
    int num = 0;
    char sign = '+';

    for (int i = 0; i < s.length(); i++) {
        char ch = s.charAt(i);

        // 1. 组合多位数
        if (Character.isDigit(ch)) {
            num = num * 10 + (ch - '0');
        }

        // 2. 遇到运算符或末尾 → 用上一个 sign 触发结算
        if (ch == '+' || ch == '-' || i == s.length() - 1) {
            switch (sign) {
                case '+': {
                    res += num;
                    break;
                }
                case '-': {
                    res -= num;
                    break;
                }
            }
            sign = ch;
            num = 0;
    }

    return res;
}
关键：结算用的是上一个运算符（sign），ch 只是触发信号并成为下一个 sign。if 不能是 else if，否则数字结尾会漏结算。

3.2 四则运算（+ - * /）LeetCode 227

int calculateMultiplyDivide(String s) {
    if (s == null || s.isEmpty()) return 0;

    int res = 0;
    int lastNum = 0;
    int num = 0;
    char sign = '+';

    for (int i = 0; i < s.length(); i++) {
        char ch = s.charAt(i);

        if (Character.isDigit(ch)) {
            num = num * 10 + (ch - '0');
        }

        if (ch == '+' || ch == '-' || ch == '*' || ch == '/' || i == s.length() - 1) {
            switch (sign) {
                case '+': {
                    res += lastNum;
                    lastNum = num;
                    break;
                }
                case '-': {
                    res += lastNum;
                    lastNum = -num;
                    break;
                }
                case '*': {
                    lastNum = lastNum * num;
                    break;
                }
                case '/': {
                    lastNum = lastNum / num;
                    break;
                }
            }
            sign = ch;
            num = 0;
        }
    }

    res += lastNum;  // 循环外补上最后一个 lastNum
    return res;
}
关键：* / 优先级高，不能立即合并到 res，需要 lastNum 缓冲。循环结束必须 res += lastNum 收尾。

3.3 带括号的加减法（+ - ( )）

int calculateWithParentheses(String s) {
    if (s == null || s.isEmpty()) return 0;

    int res = 0;
    int num = 0;
    int sign = 1;     // 1 代表 +, -1 代表 -
    Stack<Integer> stack = new Stack<>();

    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);

        if (Character.isDigit(c)) {
            num = num * 10 + (c - '0');
        }

        if (c == '+' || c == '-' || c == '(' || c == ')' || i == s.length() - 1) {
            switch (c) {
                case '+': {
                    res += sign * num;
                    sign = 1;
                    num = 0;
                    break;
                }
                case '-': {
                    res += sign * num;
                    sign = -1;
                    num = 0;
                    break;
                }
                case '(': {
                    stack.push(res);
                    stack.push(sign);
                    res = 0;
                    sign = 1;
                    num = 0;
                    break;
                }
                case ')': {
                    res += sign * num;
                    int lastSign = stack.pop();
                    int lastRes = stack.pop();
                    res = lastRes + lastSign * res;
                    num = 0;
                    break;
                }
        }
    }

    return res;
}
关键：遇到 ( 把当前 res 和 sign 入栈，开启新上下文；遇到 ) 先结算括号内，再弹栈合并回外层。sign 用 int 方便入栈。
