详细分析

1. Container With Most Water (11)

思路：两个指针从最左和最右开始，逐步缩小宽度，每次只移动短板。

面积 = min(height[i], height[j]) * (j - i)

为什么移动长板不行？宽度减小，新高度 ≤ 原短板高度 → 面积不可能增大。

if (height[i] < height[j]) i++;
else if (height[i] > height[j]) j--;
else { i++; j--; }

2. 3Sum (15)

思路：先排序，固定 i，low = i+1，high = n-1，移动 low/high 寻找 nums[i] + nums[low] + nums[high] == 0。

去重三连：

if (i > 0 && nums[i] == nums[i-1]) continue;     // i 去重
while (j < k && nums[j] == nums[j+1]) j++;         // j 去重
while (j < k && nums[k] == nums[k-1]) k--;         // k 去重

3. Best Time to Buy and Sell Stock I (121)

思路：正向扫描，记录历史最低价格，每天计算如果当天卖出能赚多少，更新最大利润。不需要逆向扫描。

4. Trapping Rain Water (42)

思路：左右指针 + 维护左右最大高度。当 height[left] < height[right] 时，left 位置的接水量仅取决于左侧最大值。

5. Best Time to Buy and Sell Stock II (122)

思路：累加所有正差价，无限次交易可以把一次长持有拆成多段短持有，总和不变。

for (int i = 1; i < prices.length; i++) {
    if (prices[i] > prices[i-1]) profit += prices[i] - prices[i-1];
}

6. Backspace String Compare (844)

思路：逆向扫描时，# 代表跳过下一个有效字符，天然适合从后往前处理。

7. Sort Colors (75)

思路：三指针（荷兰国旗问题）。

int red = 0, blue = nums.length - 1, i = 0;
while (i <= blue) {
    if (nums[i] == 0) swap(nums, red++, i++);
    else if (nums[i] == 1) i++;
    else swap(nums, blue--, i);
}

8. Shortest Unsorted Continuous Subarray (581)

思路：找备选区间 → 扩展备选区间（根据 min/max 向外扩展）→ 最终 [s, e] 即为答案。

9. Gas Station (134)

思路：从点 i 出发到 k 走不下去，则 i 到 k 之间的任意点都不需要尝试，直接跳过从 k+1 开始。

10. Assign Cookies (455)

思路：两个数组各排一次序，两个指针分别扫描。标准双数组指针模板。

11. Best Time to Buy and Sell Stock III (123)

思路：双向分割。left[i] = prices[0..i] 范围内一次交易的最大利润，right[i] = prices[i..n-1] 范围内一次交易的最大利润，ans = max(left[i] + right[i])。

12. Two Sum II - Input Array Is Sorted (167)

思路：已排序数组，左右指针。sum < target → low++，sum > target → high--。

13. Remove Duplicates from Sorted Array (26)

思路：慢指针 i 维护不重复区的末尾，快指针 j 扫描。遇到新元素就放到 i+1。

14. Move Zeroes (283)

思路：慢指针指向当前非零元素应放置的位置，快指针扫描。非零元素前移，最后末尾补零。

15. Maximum Width Ramp (962)

思路：预处理 LMin[i] = a[0..i] 的最小值，RMax[j] = a[j..n-1] 的最大值。双指针贪心扩展 j。

16. Merge Two Sorted Arrays（平方后合并）

思路：有序数组（可含负数）平方后顺序被打破，但每个数组的平方最大值必在两端之一（绝对值最大的元素位于最左或最右）。用四个指针（每数组左右各一）从两端夹逼，从大到小填充结果，天然处理负数。

为什么负数不难：-4 的平方 16 落在数组左端，正数平方落在右端，取两端 max 即得本数组当前最大平方，谁大谁先出。

int l1 = 0, r1 = a.length - 1;   // a 的左右指针
int l2 = 0, r2 = b.length - 1;   // b 的左右指针
int k = result.length - 1;        // 结果从大到小填充
while (l1 <= r1 && l2 <= r2) {
    int ca = Math.max(a[l1]*a[l1], a[r1]*a[r1]);
    int cb = Math.max(b[l2]*b[l2], b[r2]*b[r2]);
    if (ca >= cb) { result[k--] = ca; if (a[l1]*a[l1] > a[r1]*a[r1]) l1++; else r1--; }
    else          { result[k--] = cb; if (b[l2]*b[l2] > b[r2]*b[r2]) l2++; else r2--; }
}
while (l1 <= r1) { result[k--] = Math.max(a[l1]*a[l1], a[r1]*a[r1]); if (a[l1]*a[l1] > a[r1]*a[r1]) l1++; else r1--; }
while (l2 <= r2) { result[k--] = Math.max(b[l2]*b[l2], b[r2]*b[r2]); if (b[l2]*b[l2] > b[r2]*b[r2]) l2++; else r2--; }
