二分查找 死循环 可视化

理解 low = mid 时为什么必须上取整

查找 ≤ target 的最后一个位置 — 用下取整 mid → 陷入死循环
运行中 循环次数 0

数组 target = 5

目标：找到 nums[mid] ≤ target 的最后一个位置（右边界）
low mid high target
low = 0 mid = — high = 4
❌ 错误写法 — 下取整低 = mid
// 找最后一个 ≤ target 的位置
int low = 0, high = nums.length - 1;
while (low < high) {
    // ⚠️ 下取整！
    int mid = low + (high - low) / 2;
    if (nums[mid] <= target) {
        low = mid;      // ← mid 可能是答案，保留
    } else {
        high = mid - 1;
    }
}
return low;
✅ 正确写法 — 上取整 
// 找最后一个 ≤ target 的位置
int low = 0, high = nums.length - 1;
while (low < high) {
    // ✅ 上取整！
    int mid = low + (high - low + 1) / 2;
    if (nums[mid] <= target) {
        low = mid;
    } else {
        high = mid - 1;
    }
}
return low;
